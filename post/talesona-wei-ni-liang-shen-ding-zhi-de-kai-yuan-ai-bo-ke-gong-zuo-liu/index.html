TaleSona — 为你量身定制的开源 AI 播客工作流

2026-08-11 · 3 分钟阅读
Talesona 软件 开源 AI 播客 工作流

Talesona，一个由 AI 工作流驱动的播客自动生成工具——不只是输入一句话出音频，而是把资料搜集 → 文稿撰写 → 人工审校 → 本地配音 → 背景音乐混音，每一步都拆解为可视化的智能工作流。

应用简介

TaleSona（tale + sona）让播客创作从"打开录音设备"变成"描述一个想法"。你定义系列主题和工作流，AI 代理分工协作完成研究、写稿、审校、配音和配乐。语音使用本地 Kokoro TTS 合成，不上传任何文稿到第三方。（文稿生成和联网检索依赖外部 LLM API，需自行配置。）

⚠️ Beta 0.1 暂仅支持英文内容生成（TTS 声线为英文，LLM 工作流输出英文文稿）。中文及多语言支持将在后续版本加入。

典型使用场景：

  • 🎧 给孩子的英语磨耳朵素材——创建一个"睡前英文小故事"系列，输入几个关键词，AI 自动生成 3 分钟英文小故事播客，地道的英文配音 + 舒缓背景音乐，每天一集不重样
  • 📖 在语境中学习英语单词——创建一个"单词学习播客"系列，输入一组生词，AI 将它们编入一段自然对话或短文情景中，学生在真实语境中听、记、理解
  • 🗞️ 每日科技新闻简报——创建一个"Daily Tech Briefing"系列，每天输入当天感兴趣的科技话题（如 AI、太空、生物），AI 搜集资料、撰写英文简报、自动配音，5 分钟通勤听完
  • 🌍 旅行前文化播客——去一个国家之前，让 AI 生成目的地历史、风俗、实用短语的英文播客，既是行前预习又是听力练习
  • 🎙️ 个人品牌播客——创建一个固定风格的系列，定期输入自己的观点和大纲，AI 辅助扩展成完整英文播客文稿 + 配音，降低内容创作门槛

Beta 0.1 已完成功能：

  1. AI 工作流引擎——每个播客系列由一段 Python 工作流驱动，Agent 分工完成研究 → 写稿 → 审校 → 配音 → 配乐，进度以步骤列表实时呈现
  2. 人工审核节点——工作流可在关键节点暂停，等待你审阅中间稿，给出批注或退回到指定 Agent 重写
  3. 一句话创建新系列——用自然语言描述你想做的播客（主题、风格、工作流），系统自动生成对应的系列代码与输入表单
  4. 本地 Kokoro TTS 语音合成——英文声线（af_maple / af_sol / bf_vale），模型随包附带（约 380MB），开箱即用
  5. DeepSeek / OpenAI 兼容 API 驱动 AI 工作流，也支持本地 Ollama 部署
  6. Tavily 联网资料检索（可选，未配置时优雅降级）
  7. ACE Music 背景音乐混音（可选，未配置时降级为纯人声）
  8. 系列库管理——封面、置顶、删除，卡片式浏览带长按预览
  9. 单期播客生成——动态输入表单由系列工作流自动决定
  10. 内置播放器——播放/暂停、进度条、波形动画
  11. 全局搜索——按系列名或单集名检索，客户端即时过滤
  12. Windows 桌面应用——pywebview + WebView2 无边框窗口

开发中功能：

  • 播客导出（MP3 + 元数据批量导出）
  • 系列代码编辑器（在应用内直接编辑工作流）
  • macOS 支持
  • 中文及多语言支持
